# Week 1: Lock The Direction And Setup The Core

## Objective

Stop drifting. Set the product direction, lock the stack, and build the first real backend skeleton.

## Main Outcome

By the end of this week, you should have:

- a one-sentence `plantUSA` rebuild definition
- a local `NestJS + PostgreSQL` project running
- a repository structure for backend and web
- a clear data model draft
- a rewritten professional headline and short pitch

## Product Scope For This Week

Define `plantUSA rebuilt properly` in one sentence:

- "A plant-care app with custom backend, diagnosis history, AI-assisted care guidance, and follow-up workflows that turn one-off scans into ongoing plant care."

If you cannot explain the product in one sentence, your scope is still too broad.

## Build Tasks

- Create backend repo or backend folder with `NestJS`
- Choose `Prisma` or `Drizzle`
- Connect to `PostgreSQL`
- Create initial entities:
  - users
  - plants
  - plant_diagnoses
  - diagnosis_images
  - care_plans
  - reminders
  - ai_runs
  - audit_logs
- Set up environment config
- Add health-check endpoint
- Add a base module structure:
  - auth
  - users
  - plants
  - diagnoses
  - care-plans
  - reminders
  - ai
  - audit

## Study Focus

- TypeScript basics that matter in backend work:
  - interfaces
  - types
  - unions
  - generics
  - narrowing
- Node runtime basics:
  - event loop at a practical level
  - promises
  - `async/await`
  - error propagation
- NestJS architecture:
  - modules
  - controllers
  - providers
  - dependency injection

## Interview Prep Focus

Prepare short answers for:

- Why are you moving toward `Node.js + TypeScript + NestJS`?
- Why are you targeting `Product Engineer` roles instead of pure mobile roles?
- Why is your stack now `Flutter + Next.js + NestJS + PostgreSQL/Supabase`?

## Positioning Task

Rewrite these this week:

- LinkedIn headline
- resume summary
- portfolio intro paragraph

Use this base direction:

- `Product Engineer | Flutter, Next.js, TypeScript, NestJS, PostgreSQL/Supabase, AI Integration`

## End-Of-Week Deliverables

- backend project bootstrapped
- database connected
- schema draft written
- one-sentence `plantUSA` product definition finalized
- updated professional headline draft

## Red Flags

- spending the week watching tutorials without shipping setup
- changing product idea mid-week
- researching Python agents
- polishing UI before backend exists
