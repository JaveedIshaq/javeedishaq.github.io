# Week 8: Product Workflows And Real SaaS UX

## Objective

Make the product look like something a startup could use, not just an engineer demo.

## Main Outcome

By the end of this week, you should have:

- onboarding flow
- settings area
- search/filter UX
- AI diagnosis and care experience visible in UI
- audit/activity feed basics

## Build Tasks

- add onboarding flow
- add organization settings
- add search/filter on plants and diagnoses
- add AI diagnosis and care-plan UI
- add activity feed or audit timeline
- add empty states and helpful errors

## Study Focus

- forms and mutations in Next.js
- table/filter UX patterns
- onboarding structure in SaaS products
- activity feed patterns

## SaaS Architecture Focus

- onboarding
- admin/internal workflows
- auditability
- user trust in AI-assisted recommendations

## Interview Prep Focus

Prepare stories for:

- how you cut scope to keep the product usable
- how you chose which plant-care workflows mattered first
- how you exposed AI safely in the UI

## End-Of-Week Deliverables

- onboarding flow
- settings screens
- searchable workflow UI
- AI diagnosis/care page
- activity feed or audit page

## Red Flags

- endless dashboard tweaking
- no clear core workflow
- no visible user value from AI
