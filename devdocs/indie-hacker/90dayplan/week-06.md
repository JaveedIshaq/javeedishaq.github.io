# Week 6: AI Answers, Summaries, And Guardrails

## Objective

Turn retrieval into a real product workflow with reliable outputs.

## Main Outcome

By the end of this week, you should have:

- care-plan generation
- summary generation
- a basic prompt/template layer
- guardrails for low-confidence results
- stronger AI product judgment

## Build Tasks

- implement care-plan generation from diagnosis results
- add plant-health summary flow
- add follow-up reminder suggestion flow
- add fallback behavior for low-confidence diagnosis
- log prompts, inputs, and result metadata safely
- add token/cost tracking

## Study Focus

- structured outputs
- prompt shaping for product features
- fallback behavior
- hallucination containment
- guardrails and cost tracking

## Product Focus

Define when the AI should:

- suggest a diagnosis
- say it lacks enough confidence
- ask for a clearer image or more context
- provide only a safe next-step recommendation

## Interview Prep Focus

Be able to answer:

- How do you reduce hallucination risk in care recommendations?
- What guardrails did you add for low-confidence diagnoses?
- How do you measure whether the AI feature is useful?
- Why is this product feature better than a generic chat UI?

## End-Of-Week Deliverables

- care-plan generation
- summary feature
- fallback behavior
- cost tracking
- notes on AI reliability choices

## Red Flags

- vague prompts with no output discipline
- no fallback behavior
- no cost awareness
