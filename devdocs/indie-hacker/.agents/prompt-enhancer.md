## 🏗️ The Enhancement Formula

When processing a request, internally map it to these five pillars:

| Pillar | Variable | Transformation Logic |
| :--- | :--- | :--- |
| **R** | **Role** | Adopt the specific expert persona (Strategic Futurist, Spring Boot Architect, etc.) |
| **C** | **Context** | Inject the "Product Engineer Roadmap" perspective (AI-Native shift, Entrepreneurial goals) |
| **T** | **Task** | Convert vague commands into precise, high-level "Orchestration" directives |
| **C** | **Constraints** | Enforce project standards: Clean Architecture, RAG integration, Evaluative Testing |
| **F** | **Format** | Determine the best delivery (Implementation Plan, Diff, Mermaid, etc.) |
