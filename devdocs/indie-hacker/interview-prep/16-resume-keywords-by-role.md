# Resume Keywords By Role

## Goal

Use the right keyword density for the role you are targeting without turning your resume into keyword spam.

## Rule

Tailor emphasis, not identity.

Your identity stays:

- Product Engineer

Your keyword emphasis changes by role.

## Role 1: Product Engineer

### Must Emphasize

- Product Engineer
- end-to-end delivery
- Flutter
- Next.js
- TypeScript
- NestJS
- PostgreSQL
- Supabase
- AI Integration
- APIs
- admin panels
- authentication
- product workflows

### Good Resume Phrases

- built and shipped product workflows
- owned end-to-end delivery
- backend-connected mobile and web products
- practical AI features
- admin and operational systems

## Role 2: Full-Stack Product Engineer

### Must Emphasize

- React
- Next.js
- Node.js
- TypeScript
- NestJS
- PostgreSQL
- Supabase
- REST APIs
- authentication
- RBAC
- background jobs

### Good Resume Phrases

- built APIs and web/admin workflows
- delivered backend services for product systems
- designed authentication and role-aware workflows
- integrated frontend and backend delivery

## Role 3: Flutter Engineer

### Must Emphasize

- Flutter
- Dart
- BLoC / Riverpod
- mobile performance
- offline-first workflows
- API integration
- app release quality

### Keep Visible

- backend-connected workflows
- Supabase
- Next.js
- product ownership

### Avoid

- looking like a pure UI implementer

### Must Emphasize

- OpenAI API

- practical AI

### Good Resume Phrases

## Role 5: Startup Engineer

### Must Emphasize

- speed
- ownership
- full-stack delivery

- mobile + web + backend

### Good Resume Phrases

## Keyword Blocks To Reuse

### Core Stack Block

`Flutter, Next.js, React, TypeScript, Node.js, NestJS, PostgreSQL, Supabase, REST APIs, Authentication, RBAC`

### AI Block

`OpenAI API, pgvector, RAG, Structured Outputs, AI Integration, Retrieval, Summarization, Workflow Automation`

### Delivery Block

`End-to-End Delivery, Product Workflows, Admin Panels, Mobile Applications, Backend Services, Operational Systems`

## What To De-Emphasize

Unless the job explicitly requires them, reduce:

- WordPress
- old legacy tools
- generic soft skills
- buzzword-heavy AI language
- too many unrelated frameworks

## Resume Customization Checklist

Before applying:

1. read the job description carefully
2. identify repeated technical keywords
3. identify repeated product/delivery language
4. match 60-80% of relevant terms honestly
5. move the most relevant stack terms higher

## Final Rule

Do not lie.
Do not hide your direction.

Adapt emphasis so the resume says:

- this is the same engineer
- but this engineer clearly fits this role
