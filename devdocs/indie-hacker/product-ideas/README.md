# Product Ideas

This folder is for focused product concepts that support the indie-hacker plan.

Each idea should answer five things clearly:

1. Who is it for?
2. What painful problem does it solve?
3. Why is the solution worth paying for?
4. What is the smallest version worth shipping?
5. How will it get discovered, shared, and sold?

The rule for this folder:

- no vague ideas
- no random AI hype
- no broad "super apps"
- one clear buyer
- one clear promise
- one clear first version
