# AI‑Powered Activity Recommendation Flutter App
https://codecanyon.net/item/aipowered-activity-recommendation-flutter-app-personalized-mood-locationbased-suggestions/60926006?s_rank=14
**Overview**
- A commercial Flutter app that suggests personalized activities based on a user’s **mood** and **location**.
- Built with **Dart** for Android and iOS.
- Includes AI‑driven recommendation engine, mood assessments, history tracking, favorites, analytics dashboard, and an AI assistant.

**Key Features**
- AI Activity Recommender
- Mood & location based suggestions
- Assessment questionnaires
- History & results tracking
- Favorites bookmarking
- Analytics dashboard
- AI chat‑style assistant

**Technical Details**
- Language: Dart (Flutter)
- UI: modern design with gradients, glass‑morphism, micro‑animations
- Dependencies: standard Flutter packages + AI inference SDK (e.g., TensorFlow Lite or cloud endpoint)

**Getting Started**
1. Purchase and download the source from CodeCanyon.
2. Extract the zip and open the project in Android Studio or VS Code.
3. Run `flutter pub get`.
4. Launch with `flutter run` on a device or emulator.

**Customization Ideas**
- Replace the AI model with a custom endpoint.
- Extend the activity database with region‑specific options.
- Integrate wearable sensor data for richer mood detection.
