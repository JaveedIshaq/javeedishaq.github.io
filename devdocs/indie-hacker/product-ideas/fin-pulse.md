# Fin‑Pulse: AI‑Driven Expense Categorizer

| **Section** | **Details** |
|---|---|
| **App Name** | **Fin‑Pulse** |
| **Core Problem** | Personal finance apps require manual categorization of transactions, leading to inaccurate budgeting. |
| **AI Capability Used** | LLM + embeddings for transaction description understanding; optional OCR for receipt images. |
| **Target Users** | Individuals managing personal budgets, freelancers, small‑business owners. |
| **Key Features (MVP)** | 1️⃣ Connect to bank via Plaid (or import CSV).<br>2️⃣ Auto‑categorize each transaction using AI.<br>3️⃣ Highlight anomalous spend (e.g., “Unusual dining expense”).<br>4️⃣ Monthly budget insights & forecasts.<br>5️⃣ Export to CSV/Excel. |
| **Why AI Makes This Work** | Transaction descriptions are noisy; AI can infer context (e.g., “Starbucks” → “Coffee”) better than rule‑based tags, reducing user effort. |
| **Monetization Strategy** | • **Free**: up to 50 transactions/month.<br>• **Premium** $5.99 /mo for unlimited transactions, advanced forecasts, and receipt OCR.<br>• **Affiliate**: referral to credit‑card offers (optional). |
| **Marketing & Growth Angle** | • Blog posts on “how AI can save you money”.<br>• Partnerships with personal finance influencers.<br>• In‑app referral for extra free transaction slots. |
| **Why Now?** | Banking APIs are mature, AI categorization costs have dropped, and users are increasingly looking for automated budgeting tools. |
