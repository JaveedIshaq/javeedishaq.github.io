# SleepScore AI — Smart Sleep Coaching (Not Just Tracking)

## Core Problem
Sleep apps track data but don't help. Users know they sleep badly — they need personalized interventions that actually work, not more charts.

## AI Capability Used
- **On-Device ML** — Sleep pattern detection and correlation
- **LLM** — Personalized coaching and insight generation
- **Multi-Signal Analysis** — Connect sleep to daily behaviors

## Target Users
- Adults with sleep issues
- Shift workers
- New parents
- Executives with irregular schedules
- Anyone who's tried "just set a bedtime" and failed

## Key Features (MVP)

| Feature | Description |
|---------|-------------|
| Passive Tracking | Phone/watch data, no manual logging |
| Correlation Engine | Connect sleep to food, exercise, screen time |
| Micro-Interventions | Small, personalized changes that compound |
| Adaptive Sounds | AI-generated sleep stories and soundscapes |
| Weekly Experiments | "Try this one thing" suggestions |

## Why AI Makes This Work
**Without AI:** Generic tips everyone ignores.

**With AI:** "Your sleep drops 40% when you eat after 8pm AND have afternoon coffee. This week, try eating dinner by 7pm. Here's why it matters for YOUR patterns."

Personalization = actually followed advice.
