# Doc‑Snap: Visual Document Scanner & AI Extractor

| **Section** | **Details** |
|---|---|
| **App Name** | **Doc‑Snap** |
| **Core Problem** | Scanning receipts, contracts, or handwritten notes yields images that are hard to search or reuse. |
| **AI Capability Used** | Vision OCR (Google Vision) + LLM for entity extraction and classification. |
| **Target Users** | Small‑business owners, freelancers, students, anyone who handles paper receipts or contracts. |
| **Key Features (MVP)** | 1️⃣ Capture photo → auto‑crop & enhance.<br>2️⃣ OCR to text.<br>3️⃣ AI‑tagging: detect dates, amounts, parties, signatures.<br>4️⃣ Store searchable PDFs with metadata.<br>5️⃣ Export CSV/JSON for accounting tools. |
| **Why AI Makes This Work** | Accurate OCR + contextual understanding (e.g., “total due”, “invoice number”) requires vision + language models; rule‑based parsers fail on varied layouts. |
| **Monetization Strategy** | • **Free tier**: 10 scans/month.<br>• **Premium** $4.99 /mo for unlimited scans, batch export, and custom templates.<br>• **Enterprise**: volume licensing with API access for bulk processing. |
| **Marketing & Growth Angle** | • SEO on “receipt scanner app”.<br>• Partnerships with accounting SaaS (e.g., QuickBooks).<br>• In‑app referral for extra free scans. |
| **Why Now?** | Mobile cameras are excellent, OCR APIs have hit > 95 % accuracy, and AI‑driven entity extraction is now cheap enough for per‑scan pricing. |
