# AI Food Scanner App Flutter | Cal‑AI Nutrition Tracker

**Overview**
- A Flutter‑based nutrition tracker that uses AI to instantly analyze food from photos.
- Built with **Dart** for Android and iOS.
- Simplifies calorie counting by eliminating manual entry—just snap a photo to get nutritional data.

**Key Features**
- **AI Food Scanning** – Advanced image recognition identifies food items and estimates portion sizes.
- **Nutrition Analysis** – Instantly calculates calories, protein, carbs, and fats from scanned images.
- **Barcode Scanner** – Alternative logging method for packaged foods using a vast database.
- **AI Assistant** – Built‑in AI coach offers personalized diet tips and meal recommendations.
- **Progress Tracking** – Dashboards for weight, calorie intake trends, and macro breakdowns.
- **Offline Capable** – Stores scanned data locally for access without an internet connection.

**Technical Details**
- **Language:** Dart (Flutter).
- **AI Integration:** Uses models like Google Gemini or custom TensorFlow Lite setups for image recognition.
- **UI Design:** Clean, vibrant interface focused on quick interactions and data visualization.
- **Dependencies:** Camera packages, local storage (Hive/SQLite), and AI API clients.

**Getting Started**
1. Purchase and download the source from CodeCanyon.
2. Extract the zip and open the project in Android Studio or VS Code.
3. specific: Configure the AI API key (e.g., Gemini/OpenAI) in the app constants.
4. Run `flutter pub get` and launch with `flutter run`.

**Customization Ideas**
- Add diet‑specific modes (Keto, Vegan) that flag non-compliant foods.
- Integrate a recipe generator that suggests meals based on remaining daily macros.
- Connect with grocery delivery APIs to order recommended healthy foods.
